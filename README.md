# e-plantShopping

## Paradise Nursery

Paradise Nursery is a React and Redux shopping cart application for an online plant store. It features a landing page, a product listing page with plants grouped into categories, and a fully functional shopping cart with add, remove, and quantity update capabilities.

### Features
- Landing page with company welcome message and "Get Started" button
- Product listing page with plants grouped into categories (Air Purifying, Aromatic Fragrant, Insect Repellent)
- Add to Cart functionality with dynamic cart item count in the navbar
- Shopping cart page with quantity increment/decrement, item removal, and total cost calculation
- State management handled with Redux Toolkit

### Tech Stack
- React
- Redux Toolkit
- Vite

### Getting Started
```bash
npm install
npm run dev
```
